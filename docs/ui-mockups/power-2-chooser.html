Values by hand — 330 W · 1905 MHz · +75 MHz

Hand-set values are the script's set: a trial rung the machine has not measured. They are never offered as if they were measured, and a card with no plan of its own can only be moved this way or back to stock.

Nothing is installed in the boot path, by design. These are volatile driver settings: a reboot returns this card to stock on its own, and that is the way back. This page reads and writes them; it never re-applies one by itself. A rung belongs to the card, so switching configuration leaves it exactly where it is.

Nothing is drained and nothing is paused: the write is three driver calls and one read-back, a couple of seconds. It is refused while a switch, a restoration or a source deployment has the machine.
