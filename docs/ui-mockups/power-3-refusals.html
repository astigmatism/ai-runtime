2 · Written, and the driver did not agree

The apply→read-back→retry loop gave up. This is a 200 with the truth in it, not an error with the numbers thrown away: the card is in a half state, and the page has to say which half. It is the only panel that offers Revert before it offers Retry.

Values by hand

A card with no plan still gets Revert: a hand-set value written by an earlier trial is exactly what a clean number is for. This is the same shape Daisy's two RTX 2080 Ti draw — no plan line in .state/host.json, no rung offered, and no error anywhere.

4 · The machine is doing something more important

A write does not queue and does not interrupt: while a switch, a restoration or a source deployment owns the machine, the chooser reads and refuses. The values shown are still the live ones, because they are only ever a read.
